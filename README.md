# Task-Manager

General description:
A task manager that manages tasks, important dates, and classes. This is for people who struggle with procrastination and other task-management tools, such as Google Calendar or a journal. 

Features:
This also includes a lock-in session, which is basically a study session for when you need to focus for an extended period of time on work. Last but not least, it includes a coin system, which is to incentivize people to complete tasks so they can buy things from the store. There is an anti-cheating system for people who intend to use this program purely to treat it as a game. This is meant to help you get things done on time, not to game. 

How to use:
This is a website, so it should be intuitive to use. You can download the files in the folder, use git clone, or use this link: https://corvustasktracker.netlify.app
